# nova-backend

NestJS backend using Prisma and PostgreSQL.

## Setup

```bash
pnpm install
```

Copy `.env.example` to `.env` and fill in your local values.

## Prisma

```bash
pnpm prisma:generate
```

## Run

```bash
pnpm run start:dev
```

## Build

```bash
pnpm run build
```

## Test

```bash
pnpm test
```
